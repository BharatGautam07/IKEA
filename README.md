# IKEA Gifting Dataset – Learning Project

This is a learning project focused on data cleaning, customer analysis, and dashboard creation using an e-commerce dataset.

### Tools Used
- **SQL:** Data cleaning
- **Python (Pandas):** Data handling and RFM analysis
- **Power BI:** Dashboard creation and visualization

### What I Learned
- Data cleaning and preparation using SQL.
- Performing RFM analysis for customer segmentation.
- Creating interactive dashboards in Power BI.
- Using bookmarks in Power BI to create interactive dashboard views.
- Understanding customer purchasing behaviour through data analysis.

This project helped me gain practical experience in data cleaning, customer segmentation, and data visualization.
